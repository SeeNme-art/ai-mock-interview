## 7. 后续开发方向登记

这是按用户要求保留的演进信息，不是本期开发任务。以下顺序仅表示依赖或建议，最终优先级在首版完成后依据实际需要决定，不预设日期。

| 方向 | 价值 | 启动条件 / 依赖 | 首版需要保留什么 |
|---|---|---|---|
| 受控在线体验 | 让面试官或少量试用者远程操作 | 本地闭环可靠；先补访问控制、会话隔离、费用额度与部署运维；公开服务另评审 | 配置化、集中数据访问、访问者上下文入口；不声称首版已安全公网可用 |
| 基础语音输入与播报 | 更接近口头表达 | 文字题面与评分稳定；转写可确认，语音失败可回文字 | 文字作为正式输入输出，语音适配不侵入业务流程 |
| 自动打断和语音延迟优化 | 改善连续交流体验 | 基础语音可用，已测出实际瓶颈 | 分句尾部刷新、播放队列和取消机制在语音阶段明确 |
| 跨场趋势 | 回看多次练习的变化 | 有足够样本，并处理题目、难度、Prompt/rubric/模型版本及提示次数可比性 | 版本快照、分项分数、有效题数；不预先宣称能判定稳定能力 |
| 更大题库与更多方向 | 扩大知识覆盖 | 有审核材料和独立评测，现有题量确实不足 | 可扩展的维度/标签与内容版本；约 120 题是候选规模不是承诺 |
| 多岗位或更高经验层级 | 扩展使用人群 | 每个新增范围都有自己的题库、rubric 与验证样本 | Profile 边界；首版只开放已验证人群 |
| 假设场景设计题 | 评价方案与权衡 | 独立定义适用评分规则，不能直接套经历题或 STAR | 生成方式与考察任务分离 |
| 扫描件与 OCR | 支持无文本层材料 | 有实际需求及相关格式样本，能评估识别错误 | 解析适配、失败回退与确认页 |
| 教学练习模式 | 逐题讲解和针对性学习 | 模拟面试闭环稳定，明确反馈时机与成绩不可混用 | 模式边界清晰，不提前改变首版反馈规则 |
| 在线索引更新 | 不停服维护内容 | 存在持续服务需求，验证并发读取和完整版本切换 | 索引由题库重建、版本 manifest 与校验 |
| 迁移工具升级（如 Alembic） | 管理更频繁或多人维护的结构变化 | 手工脚本维护成本已明显上升 | 有序迁移历史和 schema_version |

不会作为“后续方向”复活的旧规则：按字数决定追问、模型失败给用户固定低分、未经校准的招聘结论、默认保存真实正文日志、缺乏业务需求的会话向量索引。
