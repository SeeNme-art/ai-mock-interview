## 从答题到落库

1. `score-answer` 检查同一会话的回答操作已进入 `score_pending`，在事务内登记一条待评分记录与队列操作。相同请求标识与内容复用该操作。
2. 同一 LangGraph 业务图的评分节点从业务库读取本题全部已提交问答、冻结的 rubric 和审核出处。用本地评分样例模拟候选结果。证据定位、适用维度、整数范围与计算均复用已有评分实现，调用方提供的总分不属于输入契约。
3. 校验后再次检查控制代次与业务状态。一次事务写入结果、步骤回执并收尾题目。成功评分保存分数和证据，输出失败记原因与空分。本阶段 `state` 展示评分状态，具体分数和证据在业务库中留给结场报告。

失败题的计划结果仍标为已回答。有效分数只来自 `ready` 记录，真实 0 分算一个有效分。评分模型语义、自动补评、报告与后续题在后续阶段接入。本批真实模型调用 0 次。

## 怎样复现

先按[首答保存](阶段审阅-M2首答保存.md#怎样复现)生成一场合成会话，使用默认题库并保留其首道知识原题。以下命令沿用 `$py`、`$demo` 和 `$session`。

```powershell
$state = & $py -X utf8 scripts/interview.py --db "$demo/interviews.db" state $session | ConvertFrom-Json
$stop = "$demo/no-probe.json"
@{ should_probe = $false; reason = '合成样例结束追问' } | ConvertTo-Json | Set-Content -LiteralPath $stop -Encoding utf8
$pending = & $py -X utf8 scripts/interview.py --db "$demo/interviews.db" process-answer $session $state.operation.operation_id --demo-proposal-file $stop | ConvertFrom-Json
$evidence = @(@{ exchange_id = $pending.current.exchange_id; quote = $pending.current.answer.Trim() })
$sample = "$demo/demo-score.json"
@{
  task_type = 'knowledge'
  rubric_version = 'knowledge-v1'
  dimensions = @{
    correctness = @{ applicable = $true; value = 4; reason = '合成技术正确性评价'; evidence = $evidence }
    depth = @{ applicable = $true; value = 3; reason = '合成技术深度评价'; evidence = $evidence }
    structure = @{ applicable = $false; value = $null; reason = '未考察'; evidence = @() }
    relevance = @{ applicable = $false; value = $null; reason = '未考察'; evidence = @() }
  }
} | ConvertTo-Json -Depth 7 | Set-Content -LiteralPath $sample -Encoding utf8
& $py -X utf8 scripts/interview.py --db "$demo/interviews.db" score-answer $session $pending.operation.operation_id --expected-revision $pending.revision --key demo-score --demo-assessment-file $sample
& $py -X utf8 scripts/interview.py --db "$demo/interviews.db" state $session
& $py -X utf8 -m unittest discover -s tests -p 'test_evaluation.py' -v
```

评分样例暂不可读时可用 `state` 取出排队的评分操作 ID，再用 `resume-score <session_id> <operation_id> --demo-assessment-file <path>` 继续原操作。重复调用已完成的 `resume-score` 可省略样例。
