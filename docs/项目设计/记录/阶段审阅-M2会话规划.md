日期 2026-11-21，开发基线 `6579cd8`。本批交付已确认材料会话的计划生成、预览和开始前重建。

## 计划怎样生成

1. 读取用户确认的练习模式、项目、方向、题数和难度。默认三个方向、基础难度及 5 题。混合模式目标为 3 道知识题和 2 道项目题，8 题为 5 道知识题和 3 道项目题，知识专项全部是知识题。
2. 确定性项目规则按确认材料里的关键词判断所选方向是否相关。每个相关项目可从实施和验证两个已确认字段择题，重复的字段内容只用一次。项目材料不足时由审核知识题补足，并把差异显示在计划里。
3. SQLite 按审核状态、难度读取候选，代码按选定方向与实际计划覆盖轮转，排除重复的规范化考察点。总量不足返回 `QUESTION_UNAVAILABLE`，提示调整方向、难度或题数。已生成的计划在一个事务里替换并保存回执。

预览只展示类型、顺序、方向、难度、材料入口和覆盖提示。数据库里的计划项另外保存待核对的题目修订、拟评分维度或项目字段引用，等 `start` 准备正式题面时使用。本轮规划为本地确定性规则，关键词只用于判断可利用的项目字段。FAISS 排序、语义去重与评分依据冻结随实际出题流程验证。

## 怎样复现

在仓库根目录执行，选择混合模式。项目行动可填写“实现检索分块”，验证字段可填写“用固定查询对比分块大小”。把材料确认输出的 `session_id` 填入 `$session`。

```powershell
$py = '.\.venv\Scripts\python.exe'
$demo = "data/experiments/plan-demo-$([guid]::NewGuid().ToString('N'))"
& $py -X utf8 scripts/question_bank.py --db "$demo/questions.db" import
& $py -X utf8 scripts/material_profile.py --db "$demo/interviews.db" create
$session = '<session_id>'
& $py -X utf8 scripts/interview_plan.py --db "$demo/interviews.db" --bank "$demo/questions.db" build $session --expected-revision 1 --key demo-plan-1
& $py -X utf8 scripts/interview_plan.py --db "$demo/interviews.db" show $session
& $py -X utf8 -m unittest discover -s tests -p 'test_interview_plan.py' -v
```

重复同一条 `build` 可验证幂等。修改题数或难度时用新的 `--key` 与 `show` 返回的当前 `revision`。规划与预览均为本地操作，模型调用 0 次。
