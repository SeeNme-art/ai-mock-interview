## 数据怎么走

导入命令先校验 JSON，再通过编号 SQL 初始化独立的公共题库 SQLite 库。题目和出处分别保存，用外键关联。一次导入使用一个事务，任一条失败会整批回滚。同版本原样导入会跳过，修改题目须提升 `revision`，供 FAISS 使用的数字 ID 保持稳定。出处发生实质改变时分配新来源 ID，并在新版题目中引用它。

候选查询默认仅返回 `verified` 题，可按方向、难度和已问题目 ID 筛选。作者通过后，首批 10 题从 `draft` 提升为 `verified`，修订号从 1 提高为 2。当前实现使用 Python 标准库 SQLite 与现有 Pydantic，向量排序、索引清单及用户画像存储在后续批次实现。

在项目根目录可复现导入和查询：

```powershell
.\.venv\Scripts\python.exe scripts/question_bank.py import
.\.venv\Scripts\python.exe scripts/question_bank.py list --all-statuses --dimension rag
.\.venv\Scripts\python.exe scripts/question_bank.py list
```

默认数据库为 `data/question_bank.db`。用 `--db` 可指定独立测试库。启用后实测最后一个命令返回 10 道正式候选，均为修订 2。题库 8 项测试再次通过。
