## 本机复现

从仓库根目录按[运行说明](../../../README.md#跑起来)安装三个锁定依赖文件并启动 Uvicorn。浏览器打开 [本机工作台](http://127.0.0.1:8000/)，点「使用示例」。默认本机流程只用示例材料和固定评分。复现本地向量检索时按 M1 说明安装 Embedding 依赖、准备模型并重建索引。

工程回归使用临时数据库和合成材料，回环测试需要可用的本机端口。以下检查不会调用 DeepSeek。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_offline.py --split holdout --model-dir data/index/bge-small-zh-v1.5
```

正式试测的原始证据对应 `5ad070a`。现在重跑真实试测需要重新确认费用和请求规模，并使用新的独立保留样本来评价改进。

## 五分钟演示顺序

| 时间 | 页面和动作 | 讲给面试官听的话 |
|---|---|---|
| 0:00–0:45 | 首页点「使用示例」，预览并确认材料 | 这是一款面向 Agent 岗求职者的练习工具。先确认材料，系统才把它用于规划 |
| 0:45–1:30 | 选方向，生成五题计划 | 知识题走审核库。项目题基于已确认字段。开始时冻结计划，发布每题时冻结评分依据 |
| 1:30–2:45 | 答首题和示例追问，刷新一次，再继续答题 | HTTP 保存答案后才处理。刷新从 SQLite 读取进度，重复提交复用操作回执 |
| 2:45–3:40 | 打开报告，展开一题并下载 Markdown | 知识与项目题分开显示，报告保留题目、回答和评分依据。演示反馈是固定的 |
| 3:40–5:00 | 展示保留集结果和一条失败样例 | 解释本地向量检索指标，再讲真实模型为什么没有通过发布门槛 |

也可以用一份不含个人信息的合成 DOCX，演示提取结果如何修改确认。单方向知识专项选择 8 题时可以演示候选不足提示，再改选两个方向。长演示可从历史恢复、再练或清理记录。

## 面试讲解提纲

- **数据流**：浏览器提交答案 → SQLite 原子落库与操作登记 → LangGraph 执行业务步骤 → 校验模型输出与引用 → 更新进度 → 页面读取结果。恢复源是业务库回执。LangGraph 独立 checkpoint 实验另有证据。
- **故障故事**：Edge 首次走查时有时一直不显示首题。库内已经发布了题目，页面在后台写入前只读了一次状态。加了有界轮询后复跑整场。可用 [ISSUE-011](问题记录.md#issue-011--浏览器进入面试页后首题迟迟不显示) 对照。
- **预算故事**：供应商超时会留下未知用量。系统先登记并预留再发请求，保留未核实费用。后来结束或删除会话时，匿名累计金额仍计入总额度。
- **效果故事**：报告检索对比使用相同候选集合与 Top 3。真实云端试测保持冻结门槛，例如 Q19 已讲清 ID 严格比较，模型仍追问这一点，体现了真实质量差距。
- **简历表述示例**：实现面向 Agent 岗求职者的本地模拟面试工作台，使用 LangGraph 与 SQLite 保证答题操作可恢复、重复提交可去重，建设 30 题审核库，以及材料和检索评测。真实模型经独立保留集试测，依据结果保留实验模式。

后续正式云端发布需要分阶段校准追问阈值及评分输出，建立字段级失败归因，并在新的独立保留集复验。当前还有正式图 checkpoint、手动补评和云端主问题生成等后续事项。M5 的自审提交授权到本批结束。
