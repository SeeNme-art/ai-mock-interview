## 复现调试集

按[项目启动说明](../../../README.md)安装应用依赖。要执行向量对比，另安装 `requirements-embed.txt` 并准备[本地模型](阶段审阅-M1向量检索.md#怎样复现)。从仓库根目录运行。

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_offline.py --split debug --model-dir data/index/bge-small-zh-v1.5
```

省略 `--model-dir` 时只执行标签校验与材料解析。向量对比在临时 SQLite 库中导入题库，再用同一个本地模型对同一候选集合排序，无需接触面试历史与凭据。[实验记录](实验记录.md#exp-004--扩库后的本地检索调试集) · [机器可读原始结果](实验产物/EXP-004-m4-debug-v1.json)
