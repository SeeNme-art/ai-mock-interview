## 输入怎样变成报告数字

1. 以正式题面冻结的题型、rubric 版本、适用维度和来源为准。评分结果必须包含该题型的全部维度。适用的维度接受 0–4 整数，未考察的维度必须为空。
2. 按 `exchange_id` 在该题已提交的答案中查找引用，重新计算 `start/end`。找不到原文或引用来源不在快照内，拒绝本次评分。适用维度没有引用时须提供缺证说明。
3. 单题分按适用维度等权归一化，再分别计算知识题和项目题的有效题均分。维度均值只看实际考察的样本。系统同时返回计划、展示、提交、有效评分、跳过和系统失败六项计数。

## 合成验收样例

| 项目 | 结果 |
|---|---|
| 分类均分 | 知识题的 100.0 与 12.5 汇总为 56.2，项目题均分 50.0，分别有 2 道和 1 道有效题 |
| 题目计数 | 计划 8、展示 7、已提交 6、有效评分 3、跳过 1、系统失败 2 |
| 缺分与零分 | 只问到知识题且确实评为 0 分时，知识题均分显示 0.0，项目题显示 `null` |
| 汇总完整性 | 跳过、未答、待评分或评分失败均无有效分。提前结束或存在缺评分时标记部分报告 |
| 非法输入 | 伪造引用、非整数分、越界分、直接提供单题总分、重复题目与错误考察维度均被拒绝 |

本阶段按设计的 `round(…, 1)` 使用精确分数计算，中点取偶数末位。因此 56.25 保留一位是 56.2。维度均分沿用 0–4 分尺度，相同文本重复出现时确定性采用首次引用位置。

这组样本验证数据契约与算术。正式评分提示、同题答案的数据库查询、补评及报告修订将在 M2 接入，模型质量由后续样本验证。本批调用模型 0 次。
