# M2 第十批 · 继续面试

日期 2026-11-22，开发基线 `5d6746a`。本批提供一个命令，用同一会话继续已登记但尚未完成的业务步骤。

## 从哪里继续

1. `state` 只读取业务库。它在同一个快照里判断最新操作是否属于当前会话阶段与控制代次，返回 `resume` 或 `null`。
2. `resume` 在用户明确调用时运行该操作原有的 LangGraph 节点。可继续已登记的开始、回答处理、评分、推进、跳题或结束收尾。可以指定操作 ID 与修订，避免用过期视图继续。
3. 已展示题面或已完成的步骤直接返回现有进度。已结束且收尾写成功、报告待写时只补报告。正常结场仍由 `generate-report` 明确生成报告。
4. 业务表的操作与步骤回执足以继续当前本地样例流程。本批范围止于本地 CLI，生产图 checkpoint、远程调用状态未知与自动后台恢复留在后续阶段。

## 验收结果

| 检查项 | 实际结果 |
|---|---|
| 跨进程继续 | 在不同的 CLI 进程里恢复同一会话的开始、已交回答、评分、推进和跳题。最终停在计划第 3 题，已提交答复和评分各一条 |
| 重复与并发 | 两个请求继续同一首题，只出现一条题面和一个步骤回执。继续已完成的评分返回同一份进度 |
| 安全边界 | 旧修订、错操作、错会话与失效控制代次无法产生新进度。缺追问样例时保留原答案和排队状态 |
| 结场 | 已登记中止照常收尾。若评分已存、报告写入失败，恢复时只写报告，原评分保持不变。正常结场无需继续则只读进度 |
| 定向回归 | 新增 5 项，推进与终态共 32 项通过。使用本地合成样例 |
| 测试清理与全量 | 全量两次碰到既有 Windows 临时 SQLite 占用。P0 HTTP 测试改为有序退出后，隔离三轮、全量 158 项通过，见 [ISSUE-006](问题记录.md#issue-006--p0-http-回归偶发无法清理临时观测库) |

## 怎样复现

按[首答保存](阶段审阅-M2首答保存.md#怎样复现)启动合成会话并保存答复，沿用 `$py`、`$demo`、`$session`。另开终端并恢复这些变量，从项目根目录执行以下命令。

```powershell
$state = & $py -X utf8 scripts/interview.py --db "$demo/interviews.db" state $session | ConvertFrom-Json
$proposal = "$demo/resume-proposal.json"
Set-Content -LiteralPath $proposal -Encoding utf8 '{"should_probe":false,"reason":"合成收尾样例"}'
& $py -X utf8 scripts/interview.py --db "$demo/interviews.db" resume $session --operation-id $state.resume.operation_id --expected-revision $state.revision --demo-proposal-file $proposal
& $py -X utf8 scripts/interview.py --db "$demo/interviews.db" resume $session
& $py -X utf8 -m unittest discover -s tests -p 'test_advancement.py' -v
& $py -X utf8 -m unittest discover -s tests -p 'test_finalization.py' -v
```

第一次继续后原答案仍在，`operation.decision` 为 `score_pending`。第二次返回同一进度，后续由 `score-answer` 明确登记评分。若中断的是已登记评分，继续时再传 `--demo-assessment-file`；若待出题，使用原来的 `--bank`。
