# M2 第十一批 · 会话预算

日期 2026-11-22，开发基线 `731b38e`。本批实现模型调用前预留额度、实际用量结算与未知用量保留。

## 调用如何记账

1. 用 `configure-budget` 设置会话硬上限与评分、报告的收尾预留。新库使用 v6，旧库按顺序升级并保留备份。额度一旦配置，本会话用同一上限。
2. `invoke_budgeted` 校验所属会话及操作代次，按估算输入和最大输出预留。预留和尝试记录同事务提交，然后才调用传入的单次传输。普通调用无权使用收尾预留。
3. 用已知输入、输出及缓存命中 token 和原价格快照计算费用，释放预留并转入已用。当用量未知时，账本标明待核对，预留继续占用余额。后续拿到实际用量可以补记一次。
4. 相同业务操作、步骤、尝试编号只接受一次。已发送调用的实际费用可能超过预留，账本照实记录并拦住之后的调用。

真实供应商、常规节点的自动降级、每题和全局限额待接入。当前额度与单价用于合成验证，真实试测限额另行校准。

## 怎样复现

用[首答保存](阶段审阅-M2首答保存.md#怎样复现)中的合成会话，在新会话首次配置，沿用 `$py`、`$demo` 和 `$session`。金额单位是十亿分之一美元。

```powershell
& $py -X utf8 scripts/interview.py --db "$demo/interviews.db" configure-budget $session --hard-limit-nanos 10000 --closing-reserve-nanos 1000
& $py -X utf8 scripts/interview.py --db "$demo/interviews.db" budget-status $session
& $py -X utf8 -m unittest discover -s tests -p 'test_session_budget.py' -v
```

第一条命令只配置账本。定向测试会调用合成传输，覆盖预留、放行、拦截及记账。
