## 从已提交回答到下一步

1. `process-answer` 按会话与操作 ID 读取已保存的主问题、当题问答和冻结审核要点。LangGraph 路由到同一业务图的追问节点。图状态只传 ID 和控制代次。
2. 未达上限时，显式读取本地合成建议。建议追问须属于澄清、深挖或核对矛盾之一，并引用当前轮的已提交答案。服务重新定位引用，拦截重复题面和直接复述完整参考要点的追问。
3. 发布前重查会话状态和控制代次。在同一事务增加追问轮次、保存题面和操作回执。建议收尾、达到上限或输出无效时保留答案并记为 `score_pending`，同时记录不同原因。处理完成后重放按已保存回执返回。

本批验证代码约束，模型调用 0 次。重复检测是规范化文本相等，泄露检测覆盖对完整审核要点的直接复述。改写重复、改写泄露以及追问是否真正有信息增量，将由真实模型评测覆盖。预算账本和统一网关接入后才启用真实模型路径。

## 怎样复现

先按[首答保存](阶段审阅-M2首答保存.md#怎样复现)保存一条合成回答。以下命令沿用 `$py`、`$demo` 和 `$session`。样例引用取自实际保存的答案。

```powershell
$saved = & $py -X utf8 scripts/interview.py --db "$demo/interviews.db" state $session | ConvertFrom-Json
$file = "$demo/probe-demo.json"
@{
  should_probe = $true
  purpose = 'deepen'
  reason = '样例提到权限边界，需要说明具体限制'
  evidence_refs = @(@{ exchange_id = $saved.current.exchange_id; quote = '权限范围内' })
  probe_question = '你会怎么限制模型能选择的工具？'
} | ConvertTo-Json -Depth 4 | Set-Content -LiteralPath $file -Encoding utf8
& $py -X utf8 scripts/interview.py --db "$demo/interviews.db" process-answer $session $saved.operation.operation_id --demo-proposal-file $file
& $py -X utf8 -m unittest discover -s tests -p 'test_probing.py' -v
```

若使用了不同的合成回答，把 `quote` 换成该轮答案中的原文字串。重复运行已完成的处理命令可省略样例文件。未达两轮上限且操作仍排队时，需提供可读的本地样例；这类配置问题会保留待处理状态。
