## 3. 与旧设计最重要的差异

| 旧规则 | 当前规则 |
|---|---|
| 80 字/要点命中决定追问 | 模型内容建议 + 代码动作边界 |
| 所有生成题用 STAR | 生成方式与知识/项目考察任务分开；项目技术与表达均评价 |
| 知识/经历加权 overall、招聘等级 | 两类表现分开，证据与练习建议，无整体招聘判断 |
| 所有输入必须有做法和量化结果 | 接受小项目、非量化证据；无项目可知识专项 |
| 边生成边展示题面 | 校验和保存正式题面后展示 |
| 纯 Python 完整实现后再平移图 | 先小实验理解 LangGraph，再用单一图执行业务 |
| 45 分钟墙钟强制结束 | 首版无整场限时，单操作仍有超时 |
| 失败给固定分 / 中止一律丢当前题 | 失败待补评；中止保留已提交可评估内容 |
| 8 个方向、120 题、3–5 维必选 | 首版三个方向、约 30 道审核题；方向可选 1–3 个 |
| 观测只截断正文 | 默认 metadata-only |
| 先删文件就保证一致性 | 带清理进度的幂等删除，覆盖 checkpoint 与备份 |
| 24 天、语音与趋势进入首版 | M0–M5 里程碑；语音/趋势等进入后续路线 |

具体权威规则请回正文，不把此摘要作为另一份可独立修改的规范。
