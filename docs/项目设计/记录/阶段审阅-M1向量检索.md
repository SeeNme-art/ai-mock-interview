# M1 第二批 · 本地题库检索

2026-11-21 自审完成，作者回复“审阅通过”。首批 10 道正式题已随 `9ae5b03` 推送，本批交付命令行重建和查询。

## 输入怎样变成候选题

1. SQLite 按审核状态、方向、难度、已问题 ID 筛出合格题，并在同一读取事务取得当前审核题快照。
2. 本地 `BAAI/bge-small-zh-v1.5` 将考察点、相关 JD 和技能转成向量。建库时每题用题干、考察点和最多三条要点向量化。两边均作 L2 归一化。
3. 当前约 10 题共用一个精确 FAISS `FlatIP` 索引。搜索后只在 SQLite 给出的范围内排序，再截取 Top K。返回题目修订、出处、相似度与索引和查询构造版本。

先截取全局前三再过滤，可能把一条排第四但符合条件的题一起丢掉。首版题量很小，可以搜全索引后截取合格 Top K。文档中的分片方案保留到数据规模需要时。相似度用于匹配考察点，评分依据随后由正式答题流程冻结。[FAISS 余弦距离说明](https://github.com/facebookresearch/faiss/wiki/MetricType-and-distances)

## 验收与边界

| 检查项 | 实际结果 |
|---|---|
| 在空库导入、生成并加载 | 10 道题、512 维、每个向量可用稳定数字 ID 回到题库 |
| 只返回合格题 | 自动化覆盖方向、难度、草稿、下架与已问排除；六组真实查询排除全部合格 ID 后均返回空列表 |
| 题库修订、下架或模型变化 | 清单与当前快照不符时拒绝使用旧索引并提示重建 |
| 索引文件损坏或重建中断 | 文件校验失败时不进入 FAISS 反序列化；指针替换失败时旧代次仍可查 |
| 全量回归 | Windows x64 / Python 3.12.14 的新环境兼容性检查通过，最终全量 38 项通过。中间一轮有既有 P0 测试偶发文件占用，见 [ISSUE-006](问题记录.md#issue-006--p0-http-回归偶发无法清理临时观测库) |
| 本地实际排序 | 6 条预标注合成查询，向量排序首位 6/6，SQLite 固定顺序 2/6；CPU 推理、零付费调用 |

清单包含向量配置、题目修订、题目与嵌入输入哈希、稳定数字 ID 和索引文件哈希。重建先写新代次，随后原子切换 `current` 指针。管理命令需要在停止面试服务和种子导入后运行。服务启动加载、业务降级、评分依据冻结和旧代次清理留待正式接入。哈希用于检测本地文件意外损坏，模型和索引应通过已知下载源和本仓库命令生成。[FAISS 索引读取说明](https://github.com/facebookresearch/faiss/wiki/Index-IO,-cloning-and-hyper-parameter-tuning)

独立验证覆盖当前 10 题和 6 条合成查询。题量扩大后的召回、正式业务的候选覆盖和性能仍需验证。[实验逐条结果](实验产物/EXP-003-retrieval-synthetic-debug-v1.json)

## 怎样复现

以下 PowerShell 命令在仓库根目录运行。`uv` 用于创建隔离环境并安装依赖，模型下载约 95 MB，仅第一次需要联网。命令示例中的合成材料可公开。[Qdrant 模型快照](https://huggingface.co/Qdrant/bge-small-zh-v1.5/tree/46fbe35fd4374a00fee7de77dfddaeb6dd6a2c59)

```powershell
uv venv --python .venv/Scripts/python.exe data/index/retrieval-env
$py = '.\data\index\retrieval-env\Scripts\python.exe'
uv pip install --python $py -r requirements-p0.lock.txt -r requirements-embed.txt
uv pip check --python $py
& $py -X utf8 scripts/question_bank.py import
& $py -X utf8 scripts/question_search.py prepare-model --source modelscope
& $py -X utf8 scripts/question_search.py rebuild
& $py -X utf8 scripts/question_search.py search --dimension agent --difficulty basic --objective '控制模型能调用哪些外部操作' --jd '开发有权限检查的 Agent 服务' --skill '工具调用' --skill '参数校验'
& $py -X utf8 -m unittest discover -s tests -v
```

本机验证了 ModelScope 下载路径。默认下载源为 Hugging Face，两处下载均校验固定文件哈希。查询可重复加 `--exclude` 排除题目。模型和索引在 `data/index/`，数据库默认为 `data/question_bank.db`，均已忽略。沙箱回归设置见 [ISSUE-005](问题记录.md#issue-005--沙箱临时目录的索引文件替换失败)。
