## 2. 六个合成试测任务

| ID | 准备验证什么 | 本地检查什么 |
|---|---|---|
| connection_json | 模型/端点可用，基本 JSON 返回 | ok 必须为 true |
| extract_profile | 从一句合成材料提取技能与项目 | 只接受给定技能、项目名，不接受额外字段 |
| rewrite_question | 围绕材料改写一题 | question 是非空字符串；事实与关联性需另行人工核对 |
| probe | 针对“感觉更准”决定是否追问 | boolean、目的枚举、问题字段一致；不追问时不得仍带问题 |
| score_evidence | 输出合法维度分值并引用原文 | 0–4 整数，不能用 true 当 1；引用必须在合成回答中 |
| report_suggestion | 根据固定缺口给建议 | 1–3 条非空建议；具体质量由人工看，不能靠 schema 判定 |

本轮预检不等于完整业务 Prompt 或质量验收。单项评分样例只验证返回能力，不是正式项目/知识 rubric，也不产生整体招聘分数。
